# Hai Shower v0.1.19

## Requirements Change

- **Home Assistant 2026.6.0 or newer is now required.** Since v0.1.17 the
  `bleak-retry-connector` requirement (now `>=4.6.1`) cannot be satisfied on
  Home Assistant 2026.5 and earlier (those releases ship 4.6.0 or older), so
  setup failed there with `No solution found when resolving dependencies`.
  HACS now only offers this release to versions it can install on.

## Fixes

### Alert LEDs and settings

These changes come from comparing the integration with the Hai app. They are
not yet confirmed on a real shower.

- **Alert-light enable flags now match the Hai app.** The integration sent
  different enable flags in the device's LED configuration, which likely left
  the shower's water and temperature alert lights disabled whenever Home
  Assistant re-pushed the settings.
- **LED colors now use the Hai app's values.** 7 of the 9 named colors were
  being sent with different RGB values.
- **Hai app settings are no longer overwritten.** On startup the integration
  re-sent its own alert defaults even if you had never changed an alert
  setting from Home Assistant. It now only does that once an alert setting is
  managed from Home Assistant.
- Water threshold and LED color changes now go through the combined LED
  configuration, as the Hai app does, on showers that have it. Showers on
  older firmware without it (below 550) still get the separate writes that
  earlier versions used.
- Default alert thresholds and slider ranges now follow the Hai app
  (15 gal / 90 °F defaults; water 7.5–400 L, temperature 1–48.5 °C). Values
  you have already set are kept; a temperature threshold above 48.5 °C is
  outside the new slider range.

### Water usage statistics (Energy dashboard)

- **Showers no longer show up late.** A shower synced during the same hour it
  started was only written to long-term statistics when the *next* shower
  synced, which could be days later. Closed hours are now imported shortly
  after each hour ends.
- **Showers are no longer dropped.** A session that reached Home Assistant
  after its hour had already been imported was silently skipped. It is now
  added to that hour, and later hourly totals are corrected. Totals only ever
  grow, so they cannot go backwards.

### Setup and configuration

- **Reconfigure works with discovered devices.** Choosing a discovered shower
  when correcting the Bluetooth address always failed with "choose one
  address". Submitting the form empty now keeps the current address.
- **Typing an address during setup works** when exactly one shower was
  discovered (it failed the same way).
- **"Ignore" on a discovered shower works.**
- **A missing or invalid device key now starts re-authentication** instead of
  failing setup with no way to recover short of deleting the integration.
- Closing the setup dialog part-way no longer leaves a cloud connection open.
- Submitting the device-selection step no longer opens a second Bluetooth
  connection.

### Runtime

- **Polling stops when the integration is unloaded or reloaded.** Previously
  the 30-second poll kept running in the background.
- **Flow rate and battery keep updating during a shower.** Live temperature
  updates were resetting the poll timer, so those readings could freeze for
  the whole shower.
- A stalled Bluetooth read now marks the refresh as failed instead of
  reporting the shower as being monitored.
- A late disconnect from an old Bluetooth connection can no longer drop the
  live one.
- The shower's clock is synced at most once an hour, and history sync waits up
  to 120 s, matching the Hai app.
- Downloading diagnostics no longer fails while the integration is not loaded.

## Upgrade Notes

- Requires Home Assistant 2026.6.0 or newer.
- No configuration changes are required. Existing entities, settings and
  statistics are kept.
- After upgrading, the first statistics pass may add showers that earlier
  versions missed to their original hours.
- The firmware version sensor is still disabled by default. This release
  starts reading the version from Bluetooth advertisements, as the Hai app
  does; enable the sensor if you want to try it.
