# Hai Shower v0.1.18

## Fixes

- **Integration setup failed on most Home Assistant versions** (#2) — the
  `bleak-retry-connector` requirement is now a minimum-version constraint
  (`>=4.6.1`) instead of an exact pin. v0.1.17 pinned exactly `4.6.3` to match
  one specific Home Assistant Core release, which made setup fail on every
  instance that ships a different version: Core 2026.7.x pins `4.6.1` (too old
  for the requirement) and newer Core releases pin `4.7.0` (too new). Either way
  the resolver reported `No solution found when resolving dependencies` and
  `Setup failed for custom integration 'hai_shower'`.

  A minimum-version constraint resolves against whichever version Home
  Assistant already ships, so no package is installed and no conflict can
  occur. The integration only uses `establish_connection`, whose signature is
  unchanged across 4.6.1 through 4.7.0.

  Reported by @strabbit, who also identified the correct fix.

## Upgrade Notes

- No configuration changes are required.
- No shower runtime behavior changed in this release.
- If you rolled back to 0.1.16 as a workaround, upgrade to 0.1.18. The 0.1.16
  pin (`==4.6.1`) only works on Home Assistant Core releases that ship exactly
  that version and fails on current releases.
