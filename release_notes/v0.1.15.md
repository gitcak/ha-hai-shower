# Hai Shower v0.1.15

## Fixes

- **Usage-record timestamps wrong (~2028 dates)** — the stock Hai app XOR-decrypts
  all 18 bytes before reading fields (Hermes `_readUsageRecord`). The retired
  mixed-format parser (`0:12` encrypted, `12:18` plaintext) misread
  `start_time` while session id/duration/volume still looked plausible. Parsing
  now matches the app; stored records are repaired on startup and statistics are
  backfilled from the corrected history.
- **Statistics repair backfill double-counting** — repair migration now rebuilds
  cumulative external-stat sums from zero instead of seeding from the latest
  recorder bucket.

## Operational Notes

- Restart Home Assistant after updating. On first startup, v0.1.15 repairs
  mis-decoded `start_time` values in local usage storage and re-imports closed
  hourly statistics buckets.
- Live-validated on HA 2026.7.1: session 1184 now reports
  `2026-07-06T21:34:56Z` in diagnostics.

## Known Limitations

- Firmware version remains unavailable through ESPHome Bluetooth proxy
  security limits.
- App-side alert-setting changes are not yet read back into Home Assistant.
