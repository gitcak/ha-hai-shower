# Hai Shower v0.1.13

## Improvements

- **More stable Energy water totals** - `Total water usage` now uses persisted
  lifetime counters instead of only the capped recent-record cache. This keeps
  the Energy-facing water total monotonic after the local usage history reaches
  the 250-record retention cap.
- **Home Assistant 2026.6+ Energy guidance** - setup docs now recommend adding
  `Total water usage` as an individual water device for the shower and using
  an upstream whole-home water meter when applicable.
- **Dependency pinning** - `bleak-retry-connector` is pinned to `4.6.1`.

## Fixes

- Diagnostics and default entity attributes no longer expose the Hai Product
  ID.
- The `shower_count` sensor no longer exposes detailed recent session history
  in default state attributes.
- Product-ID debug logging now uses a shortened identifier and omits raw
  product payload bytes.

## Operational Notes

- No Home Assistant config-entry migration is required.
- Existing stored usage records migrate lazily on load. Existing recorder
  statistic IDs and entity unique IDs are unchanged.
- Restart Home Assistant after HACS updates the integration.

## Known Limitations

- Firmware version remains unavailable through ESPHome Bluetooth proxy
  security limits.
- App-side alert-setting changes are not yet read back into Home Assistant.
