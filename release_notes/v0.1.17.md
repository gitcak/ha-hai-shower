# Hai Shower v0.1.17

## Fixes

- **Home Assistant dependency compatibility** — updated the integration's
  `bleak-retry-connector` requirement from 4.6.1 to 4.6.3 to match the exact
  version required by current Home Assistant Core releases. This resolves the
  package-resolver conflict that prevented Hai Shower from installing its
  requirements and aborted integration setup.

## Upgrade Notes

- No configuration changes are required.
- No shower runtime behavior changed in this release.
